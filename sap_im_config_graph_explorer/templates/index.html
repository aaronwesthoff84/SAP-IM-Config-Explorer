    AI Features Disabled

    The AI-Generated Documentation feature is currently disabled. To enable it, please configure a local or online provider.

    Configuration Instructions

    1. Set the environment variable SAP_IM_AI_PROVIDER to stub or openai.
    2. If using openai, set SAP_IM_AI_ENDPOINT to your loopback/local API endpoint (e.g., http://127.0.0.1:11434/v1/chat/completions) and SAP_IM_AI_MODEL to your desired model.
    3. Restart the application server.

    Privacy Behavior & Data Flow

    • Local-First: By default, all configuration content and XML files stay entirely on your workstation. No data is sent to external cloud services unless explicitly configured and consented to.
    • Loopback API Restriction: If an online provider is configured, the system strictly enforces loopback/local API endpoints (e.g. localhost/127.0.0.1) by default to prevent data leakage. Non-loopback endpoints are rejected.
    • User Consent: Data is only sent to the configured AI endpoint when you click the "Generate AI Documentation" button.
